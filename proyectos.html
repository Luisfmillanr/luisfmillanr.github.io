Proyectos y casos de trabajo

Ejercicios de análisis, organización e implementación de soluciones digitales. El foco no está solo en la herramienta usada, sino en entender una necesidad y construir una respuesta funcional.

Sistema de gestión

Python SQLite

Sistema de gestión de inventarios

Problema La gestión manual de productos genera desorden, errores de registro y dificultad para controlar información importante.
Solución Herramienta orientada a organizar productos, registrar información y facilitar la consulta de datos de forma clara.
Aprendizaje Una solución digital debe ser simple, comprensible y útil para quien necesita tomar decisiones, no solo técnicamente correcta.
Python SQLite Gestión de datos Organización de información

Conversor de divisas

Java API

Conversor de monedas

Problema La conversión de divisas requiere consultar valores actualizados y presentar resultados de forma clara y confiable.
Solución Aplicación que consulta información externa mediante una API y presenta los resultados con una estructura ordenada.
Aprendizaje Incluso una herramienta pequeña requiere pensar en experiencia de usuario, validación de datos y claridad en la presentación.
Java Maven Consumo de API Validación de datos

Sitio web personal

HTML CSS GitHub Pages

Rediseño de sitio personal

Problema El sitio anterior comunicaba un perfil de programador que no representaba el enfoque actual hacia consultoría tecnológica y mejora de procesos.
Solución Rediseño completo del sitio personal con mensaje claro, secciones de servicios, método de trabajo, proyectos y artículos. Publicado en GitHub Pages.
Aprendizaje Un sitio web no solo debe verse bien: debe comunicar con claridad quién eres, qué haces y qué valor entregas.
HTML CSS JavaScript GitHub Pages Diseño responsive
